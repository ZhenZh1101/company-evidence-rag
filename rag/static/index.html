How indexing and retrieval work

This project implements RAG for public-company disclosures, extending the basic “chunk → vector search → generate” pipeline with context-preserving indexing and retrieval that covers multiple parts of a question.

Read moreShow less

During indexing, documents are first parsed into structural segments such as pages, sections, and tables, then split into chunks of up to 2,600 characters. Prose chunks retain some overlap, while long table chunks repeat detected headers and nearby context where available, helping preserve fiscal periods and units alongside numerical values. Each chunk is linked to its company, disclosure date, source URL, and location in the original document. SQLite stores the source text, metadata, and embedding cache, with FTS5 providing a keyword index; vectors and filter metadata are synchronized to Qdrant for vector search. Unchanged files are skipped, and identical chunk text shares cached embeddings through content hashing, supporting incremental ingestion and resumable embedding generation.

At retrieval time, the system preserves the original question and, by default, generates up to three English search queries to match English-language disclosures and break down comparison questions. Company-specific subqueries are routed to the relevant company. Within the metadata-filtered scope, BM25 keyword search and cosine-similarity vector search in Qdrant retrieve candidates, which are combined using Reciprocal Rank Fusion (RRF). This combines exact-term matching with semantic similarity without directly mixing their raw scores. Result selection removes duplicate text, prioritizes candidates from different subqueries and companies, and limits contributions from any single document during ordinary retrieval. For cross-company questions, the system retrieves up to 48 candidates and uses the same chat model to select evidence, favoring passages with explicit periods, units, and precise reported figures. Compared with a basic single-query vector Top-K implementation, the emphasis is on retrieving the evidence needed for each part of the question and preserving enough context to interpret it.
